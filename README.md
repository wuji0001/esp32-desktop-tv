# ESP32-C3 桌面小电视

适配 4MB ESP32-C3、240×240 ST7789 小电视。包含原厂 C3 SD2 V1.7 的脱敏发布镜像、可网页配置的新闻时钟固件，以及 GitHub Actions / Pages 中文国际新闻服务。

## 新闻服务

GitHub Actions 约每 10 分钟抓取一次 BBC 中文、RFI 中文、DW 中文、中央社、联合国健康新闻，并使用 Bing 中有明确原始媒体的中文结果补充。只保留北京时间当天的中文标题，排除广告、投稿、部分评论栏目；保留原始媒体与文章链接。来源分散并不等于逐条完成事实核查，读者可访问原文。

Pages 地址：`https://wuji0001.github.io/esp32-desktop-tv/`；设备接口为同目录的 `news.json`。网页设置由 ESP32 自己托管，新闻由设备通过带证书校验的 HTTPS 读取，部署后无需 Mac 或个人 VPS 常驻。

GitHub 的定时任务可能排队延迟，不能承诺严格实时。在公共仓库长时间无活动时，GitHub 也可能停用定时任务。本项目会在公开新闻缓存内容变化时提交缓存，便于追踪内容更新。

## 固件功能

- 时钟、日期、天气、空气质量、动画，以及信息栏从右向左的中文跑马灯。
- 页面可配置小时、分钟、秒、日期、新闻颜色，亮度、方向、天气城市和刷新间隔。
- 新闻条数 1–10、分类、来源、滚动速度及是否穿插天气/IP，可保存并在重启后保留。
- 只显示当天新闻，跨午夜清理前一天标题。
- 新闻中文点阵字体覆盖 7,685 个字符，占 330,455 字节；此前灰度字体约 2.13MB。极少数字或表情可能显示占位符。
- 当前自定义版不包含原厂完整股票、相册及所有菜单；原厂包另行保留。

## 原厂脱敏包

`original-C3-SD2-V1.7-clean.bin` 是 4MB 完整地址布局的发布镜像，烧录地址为 `0x0`，并非带个人状态的原始备份。

已清除 NVS/Wi-Fi/EEPROM 配置、OTA 状态、崩溃转储和未使用区域；文件系统重新打包，仅保留原厂 HTML/CSS/JS、图标和厂商风景示例图。个人/演示上传图片不包含在发布镜像中。实际本地 Wi-Fi 凭据匹配扫描通过，原厂应用和启动程序的校验保持有效。厂商通用示例常量属于原始程序的一部分，未随意修改可执行代码。首次启动需重新配网。

本地完整私有备份没有上传。此脱敏镜像已验证结构、文件系统和应用校验；没有为了验证发布包而覆盖当前设备的手动配置。详情和 SHA-256 见 `original-sanitization.json`。

## 自定义包与接线

修改版的编译源码、许可证和烧录分段以 `custom-firmware-package.zip` 提供；包内 README 说明烧录地址。不要将自定义 app 分段按原厂完整镜像地址烧录。

本机已验证接线：SCLK=3、MOSI=5、DC=2、RST=6、CS=-1、背光=1 且低电平点亮，SPI 10MHz、ST7789_2_DRIVER。不同硬件型号须重新核对。

## 本地调试

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python test_esp32_news_feed.py
python publish_news.py
```

如需临时局域网转发，可运行 `esp32_news_feed.py --bind <LAN_IP>`。正式独立运行使用 Pages 地址，不需要保留这个进程。
